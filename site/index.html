A structured second read for quantitative social-science manuscripts

ReviScope runs a set of focused AI review modules over a manuscript and returns a list of specific, checkable points, each linked to a quoted passage and, where it can, a suggested response.

It is meant for authors who want development feedback on a draft: things to check, clarify or argue more carefully before others read it. It does not judge whether a paper is good, and it has not been validated against human peer review.

What it is, and what it is not

Use it for

  • Feedback on your own draft before submission or circulation
  • Prompts to re-check statistics, tables, claims and citations
  • Spotting places where a reader may stumble or over-read a result
  • Experimenting with discipline-specific review criteria

Do not use it for

  • Deciding whether a paper should be published or funded
  • Replacing a qualified human reviewer
  • Scoring or ranking manuscripts or researchers
  • Confidential manuscripts you are not authorised to share with a model provider

Treat every point as a question to look into, not a verdict. The reviews can miss serious problems, state a criticism that does not hold, or sound more confident than they should. An empty or short review does not mean a paper is sound.

How a review is built

Instead of one long prompt, ReviScope splits the work so that each step has a narrow job and leaves a record. The default profile covers quantitative social psychology.

  1. Screening. The metacheck R package runs deterministic checks (reported statistics, references, preregistration and open-practice statements) and passes its results on as unverified leads.
  2. Specialist modules. Separate modules review contribution, design, measurement, statistical inference, interpretation and consistency, alongside a whole-paper overview. A blind-spot pass then looks for what they missed. Modules can search the literature, recompute statistics in a restricted computing environment and look at page images of tables.
  3. Verification. A separate call checks each candidate point, ideally with a different model family. A point is published only if the verifier supports it and it has a checked quotation from the manuscript or its supplementary files; points the verifier cannot settle are listed separately as unconfirmed. Verifier support is another model's judgement, not proof that a criticism is correct.
  4. Editorial and reader passes. Overlapping points are merged and given a severity. A final pass rewrites them for clarity and proportion, without adding claims.

You receive a readable review (each finding shows the manuscript passage, then the problem, then a suggested response) and a separate audit record with the verification notes, set-aside points and every tool call.

Evaluation is ongoing

ReviScope is under active development, and I do not yet know how useful its feedback is. The checks so far guide development; none of them is a validation.

  • Planted errors. Earlier versions were run on two papers from Paul Litvak's benchmark of errors planted in psychology papers (data), and compared with a single prompt to the same model. This tests one narrow part of review, and some of the planted targets are questionable as errors.
  • Human reviews. Comparisons with the published reviews of openly reviewed Meta-Psychology submissions, with criticisms judged point by point by AI models (not yet by human experts).
  • Author ratings. Whether an author finds the points correct and would act on them, so far on my own drafts.

Whether the extra stages add value over a single careful prompt is one of the questions being tested. A held-out set of papers is reserved for validation. Until that has run, treat any impression of quality, good or bad, as anecdotal. Validation plan · development record.

Try it

You need a logged-in Codex CLI or Claude CLI; model calls run through your own subscription or account. PDF, DOCX, Markdown and plain text are supported; scanned PDFs need OCR first.

Where your manuscript goes. The text is sent to the model service your CLI uses, and saved in the local run folder. By default, metacheck screening also uploads the manuscript to an online conversion server (unless you run a local GROBID server), sends the title and abstract to a hosted classifier, and queries CrossRef and other scholarly services. Add --no-metacheck to skip these.

Ask your coding agent

If you use Codex, Claude Code or a similar agent, paste this prompt and replace the path:

Install ReviScope from https://github.com/LukasWallrich/reviscope by following
its README, then review my manuscript at PATH/TO/draft.pdf.
- Use --backend codex --model gpt-6.1-sol --effort high. If the Claude CLI
  is also logged in, add --verifier-backend claude --verifier-model
  claude-opus-5-5. If only Claude is available, use --backend claude
  --model claude-opus-5-5. Do not substitute another model or API service.
- Before processing the manuscript, explain which services will receive it
  (the model service, and metacheck's conversion upload, title/abstract
  classifier and reference lookups). Wait for my answer. Add --no-metacheck
  if I decline metacheck; stop if I decline the model service.
- Write the output to runs/my-draft. When it finishes, tell me about any
  partial or failed stages, open runs/my-draft/review.html and summarise its
  critical and major findings, keeping unconfirmed concerns separate. Do not
  add criticisms or your own judgement of the paper.

Or use the command line

This needs Python 3.11+ and uv.

git clone https://github.com/LukasWallrich/reviscope.git
cd reviscope
uv sync --extra dev

# Offline demo: no model, no credentials (output is a fixture, not a review)
uv run reviscope review examples/demo_manuscript.md \
  --backend fixture --no-metacheck --out runs/demo

# A review of your draft, with a verifier from a different model family
uv run reviscope review draft.pdf \
  --backend codex --model gpt-6.1-sol --effort high \
  --verifier-backend claude --verifier-model claude-opus-5-5 \
  --out runs/my-draft

Open runs/my-draft/review.html when it finishes. Drop the two verifier options if you only have Codex, or use --backend claude --model claude-opus-5-5 if you only have Claude. Add --supplement appendix.pdf or --preregistration registration.md if you have them. A full paper can take a long time; rerunning the same command reuses finished stages. Metacheck screening needs R 4.5 or later with metacheck installed (plus pandoc and tectonic for Markdown or plain text); add --no-metacheck to skip it. The README has the full options.

Feedback and contributions

If you run it on a draft, I would like to hear which points you acted on, which were wrong or beside the point, and what an experienced colleague caught that it did not. Open an issue; please do not paste unpublished manuscript text into a public issue.

Profiles for other fields are welcome as pull requests. Review criteria live in profiles, sets of plain-text instructions that can inherit the bundled quantitative social-science modules and add what your field checks for: its designs, measures, reporting standards and the practices that should not be criticised by rote. The education profile shows the structure; it is a demonstration, not a validated education reviewer. Open a pull request with your profile and a short note on how you tried it.
