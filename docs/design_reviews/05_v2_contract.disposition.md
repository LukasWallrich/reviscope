# Disposition of Fable v2 contract review

The BLOCK verdict is accepted. A real v2 run must not start until the verifier exception scope and editorial failure behavior are fixed and regression-tested.

The scientific prompt checks passed: genre and maturity, restraint, absence-versus-failure, acknowledged-limit scope mismatch, retrospective preregistration, generic prose/table consistency, and separate remedy assessment. No benchmark-specific facts were added.

Core changes requested before release:

- initialize verification artifact state in the correct scope and always render a partial audit on failure;
- fail editorial processing closed, never by publishing all pending findings;
- expose severity guidance to generation and editorial stages;
- enforce kept, equal-or-higher-support merge targets;
- prioritize epistemic support before severity at the publication cap;
- assign statistical leads Minor until verified and shown consequential;
- add shared non-contribution triage guidance;
- label verification provenance `not_run` after failure or skip;
- keep remedy assessment out of claim rationale.

The v2 editorial wording was revised before this review: severity and substantive text remain immutable, the editor selects an already proportionate canonical candidate, and an overreaching remedy is withheld automatically without discarding a supported claim or inventing replacement advice.
