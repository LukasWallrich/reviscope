The four Nature Human Behaviour papers are immediately promising for the intended human-review comparison. All have official review bundles. They still need a focused comparison of the historical manuscript with the initial-round review references before review generation. Preserve all reports from the matched round; do not select reviewers by apparent quality. For Bohn et al., the PsyArXiv record itself was created eight days before receipt, while immutable file revision 2 was uploaded on the receipt date; the [additional provenance record](submission-preprints-additional.md) preserves both dates, the hashes, and the exact review-bundle link.

Salvador is a valid manuscript-acquisition example, but not yet a human-review benchmark. Its historical preprint describes 37 countries while the final article describes 39; this does not itself disqualify the preprint, since additions during review are expected. It does make the pinned historical version essential.

## Acquisition lesson and evidence

The OSF API does not expose `doi` as a filterable preprint field. DOI-linked records were useful leads, but title matching and version-history checks were necessary. An OSF `_v1` preprint URL can serve a replacement file uploaded after acceptance. The links above therefore pin the underlying file **revision**, and the downloaded files are hashed in the detailed records.
